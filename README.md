# Vũ Phương Nghi — Academic Portfolio (updated)

## Quick start
Open `index.html` or run a local web server in this folder:

```bash
python3 -m http.server 8000
```

Then go to `http://localhost:8000/`.

The **four original academic files** live in the `projects/` folder. They are linked using relative local URLs so downloads work on localhost and on a properly deployed static site (provided you upload the entire folder, not only index.html).

The provided portrait is stored in `assets/vu-phuong-nghi-portrait.jpg` and used on Home and About.

Documents are coursework and proposals, not published research; group contributors are credited in the project detail modals. The contact address is phuongnghivu96@gmail.com. Other sample/placeholder professional details still require confirmation.

The Download button links to the original CV and cover letter PDF in `assets/Vu_Phuong_Nghi_CV.pdf`. Keep this file with the website when copying or deploying it.
